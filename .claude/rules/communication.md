# 応答と作業報告のルール

## 概要

ユーザーへの出力はすべて日本語で書き、実装作業が終わったら操作キー・実装内容・確認結果・未対応点を報告する。

## 言語

- ユーザーへの応答・報告・質問は **すべて日本語** で書く。英語の指示ファイル（CLAUDE.md・godot-gdscript.md）を読んだ後でも、出力は日本語にする。
- コード・識別子・ファイルパス・コマンドは原文のまま書いてよい。

## 作業完了時の報告（MUST）

実装作業が終わったら、最後に以下を日本語でまとめて報告する。

1. **操作キー**: 追加・変更した入力があれば、キーボードとゲームパッドの割り当てを表で示す（既存の割り当ても関係するものは併記）。
2. **実装した内容**: 新規ファイルと変更した既存ファイルを分けて、それぞれ何をしたかを書く。
3. **確認したこと**: 型チェック・ヘッドレス実行など、実際に確かめたことと、確かめていないこと（見た目など）。
4. **未対応・注意点**: 残っている作業や、既知の問題。

**Why:** ユーザーから「終わった後に実装した内容を教えてください」「日本語で出力してください」と指示があったため（2026-11-13）。
