# 忍者アドベンチャー 素材カタログと規約

Godot 4.3 プロジェクト `~/godot/NinjaAdventure-main`。このセッションの担当は**素材とデータ**（実装はしない）。
術の仕様（術名・ID・印・術符・レベル）の正は `忍術システム仕様.md`。素材側のJSONはそれに合わせる。

このカタログは2か所にある（Projects の `claude/素材カタログと規約.md` と、Godotプロジェクトの `document/素材カタログと規約.md`）。直すときは両方を同じ内容にする。

## 共通の規約
- 1マス = 16px。キャラ（ninja_main）は 32×32 セル、見た目の中心はセル内 (16,17)。
- シートの並び: **列 = 向き、行 = コマ**。4方向は 0=down,1=up,2=left,3=right（`SpriteCharacter.FrameDirection` と同じ）。8方向は 0=右から時計回りに45°ずつ（列 = `posmod(roundi(angle/(PI/4)),8)`）。
- 30fps。エフェクトの基準点は JSON の `pivot_in_cell`（多くはキャラの見た目の中心）。キャラSprite位置 + (0,1) に置く。
- エフェクトは pixelfx（JS, MIT）で描き、`render.mjs` でPNG化、Pythonで整形。ソースは各フォルダの `source/fx/`、プレビューGIFは `source/preview/`（`.gdignore` 済み）。
- 明かり・画面フラッシュ・揺れはシートに焼き込まず、ゲーム側（PointLight2D等）。パーティクル化はブラッシュアップ時に検討。
- UIは1倍のドット絵。CanvasLayerを3〜4倍に拡大し Nearest で表示。
- 拾えるアイテムは 16×16 セル。輪郭は濃い色 #141b1b（既存のコイン・鍵と同じ）。
- 各術のJSONの先頭に `jutsu_id` / `jutsu_name` / `element`（印）/ `talisman`（術符の使用・消費枚数。未定の値は「未定」）を持たせる。

### 術符アイテムの詳細
- コマの順番: 0=火（炎・赤） / 1=水（しずく・青） / 2=風（渦・緑） / 3=雷（稲妻・黄） / 4=土（山・茶） / 5=陽（太陽・橙） / 6=陰（三日月・紫、紙が黒）。
- 色と記号の両方で見分けられる。陰だけ紙を黒くして、陽と対にした。
- 術符の所持数は術ごとに別々だが、絵は印で共通。各術の術符は、その術の印のコマを使う（JSONの `frame_from_element`）。
- 基準点はセル内 (7,8)（札の見た目の中心）。光・上下にふわふわ揺らす・取る演出はGodot側で付ける。
- 氷は未作成。必要になったら frame 7 として追加する。
- 生成スクリプト: `source/gen_talisman_items.py`、拡大プレビュー: `source/preview/`。

### 宝箱の詳細
- 種類: 普通 normal（木＋鉄の帯。マップに置く。お金・術符・アイテム等）／銀 silver・金 gold（普通と同じ大きさ）／レア rare（赤い漆＋金の縁、青い宝石の錠。お金・レア度の高いアイテム）／古 ancient（青緑の古びた箱＋苔、古い青銅の錠。術の巻物や重要アイテムが1つ）／カラクリ karakuri（ボスが落とす。いちばん大きい。歯車が回り、左右の留め金が外れてから開く）。
- コマ: row 0 = 閉じた状態 → squash(3) → lift(2) → lid_up(2) → lid_back(2) → opened（最後のコマで止める）。カラクリだけ row 1〜4 に歯車の仕掛け（各3）が入る。数字は30fpsでのコマ数。
- 基準点: セル内 (16,29) が箱の下端の中心。Sprite2D(centered) なら offset=(0,-13)。今ある `chest.tscn`（コード側が作成。まだ旧素材 LittleTreasureChest.png を使用）の当たり判定に合わせるなら offset=(0,-9)。当たり判定の幅の目安は JSON の `collision_hint`。
- 中身が飛び出す・光る・揺れる演出はGodot側。古の宝箱に封印の札は付けない。
- 生成スクリプト: `source/gen_chests.py`、プレビュー: `source/preview/`。

## 決定事項
- 霧隠れは「ボフッと消える」案をやめ、蜃気楼のように揺らいで消える（キャラにシェーダー）。周囲の霧は術を使った場所に残す。
- 術の選択は長押しで開く8方向ホイール。マウス方向で選択、クリックで決定、開いている間は time_scale 0.2。
- 8方向化は「回転させず、方向ごとに描き直したシート」で行う。
- 術にはレベルがある（スロット左上の金バッジ、最大レベルで紫）。
- 術符は採用。術ごとに別々の所持数。表示はスロット右下のバッジで、術ごと・システムごとにオン/オフ可能。足りないときは赤バッジ＋アイコン半透明、自動で他の術に切り替えない。
- 術符のアイテム画像は印ごとに7種類（火・水・風・雷・土・陽・陰）。色と記号の両方で見分ける。
- 三段斬りは基本攻撃（術符なし）。今はホイールのスロットに置いてあるが、別ボタンに移してもよい。
- 通常攻撃は白い斬撃＋クナイ（別スプライト、攻撃中だけ表示、16方向に事前回転）。1段目は反時計回り、2段目は時計回りに振る（キャラの振りかぶりに合わせて旧データから入れ替え）。
- 三段斬りの攻撃はカーソルの正確な角度で出す。斬撃とクナイは最寄りの8方向の絵を、残りの角度（最大±22.5°）だけ回して合わせる（JSONの「回転させない」より操作感を優先）。踏み込みは 5/5/10px（Godot側の `lunge_px`。JSONの値 0/0/3 は使わない）。クナイは向き16段階の絵をコマごとに切り替える。
- 武器は別スプライトで重ねる方針。
- 被弾・戦闘不能: 採用は「戦闘不能の弾け」と「気絶の星」だけ。ヒット火花・白フラッシュ版・ヒットストップやノックバックのタイミングは不採用で、Godot側で作る。
- 画面UIの候補（A 墨 / B 和紙 / C 藍と金）は白紙に戻した（2026-11-18）。
- 宝箱は 普通・銀・金・レア・古・カラクリ の6種。古の宝箱に札は付けない（2026-11-19）。
