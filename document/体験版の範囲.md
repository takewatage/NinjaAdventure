# 体験版の範囲（段階0）

最終更新: 2026-11-18

体験版（ミニマム）で作る範囲のメモ。**決まったこと**と**未定のこと**を分けて書く。
術と術符の仕様は `忍術システム仕様.md`、物語は `ストーリー骨組み.md` が正。

---

## 1. 大きな流れ（決定）

```
村 → ワールド探索（地続きのフィールド） → ボス
```

- 範囲は**最初のエリアのボスまで**。場面の流れは `ストーリー骨組み.md` 3章。

## 2. 村（決定）

| 施設 | できること | 状態 |
|---|---|---|
| 術符屋 | 術符（術の弾薬）を買う。補充の主な手段は拾うこと | 決定 |
| 修行場 | 巻物を持ち込んで術を覚える。前提条件の確認もここ | 決定 |
| 道具屋 | 道具を買う。素材を売る | 決定 |
| 自分の家 | 倉庫、セーブ | 決定 |

- セーブは家以外でもできる。フィールドでは**焚き火**がセーブポイント。焚き火でできるのは**セーブだけ**（決定）。
- 術のレベルは修行場では上げない。使うほど術ごとに自動で上がる（`忍術システム仕様.md` 4章）。

## 3. ワールド（一部決定）

- 形式: **地続きのフィールド**。村の出口から歩いて出て、画面ごとに切り替わる（ゼルダ式）。
- できること（決定）:
  - 敵との戦闘・素材集め
  - 宝箱・隠し要素（巻物や道具が手に入る）
  - 術を使う仕掛け（例: 火で草を燃やす、岩戸で岩を押す）
  - 焚き火でセーブ
- エリア（決定）: 2つ。
  1. **村の外（チュートリアルの道）**: 負けイベントと再戦の場所。
  2. **ボスまでの道**: 巻物・術符を拾いながら進み、奥にボス。
- 依頼は**体験版では入れない**（決定）。
- 実装の状況（2026-11-18）: 村 → チュートリアルの道 → ボスまでの道 を出入口でつないだ。道の2マップは仮（草・外周の木・スライム・焚き火）で、見た目は後で描き直す。村の出口は上の道の突き当たり。ボスの場所はボスまでの道の一番上（今は空き地）。

## 4. お金の入手（決定）

- 敵が落とす
- 宝箱・草や壺から出る
- 素材を道具屋で売る

## 5. 術（決定）

- 体験版に入れるのは **4術**。

| 覚える時期 | 術 | 効果 |
|---|---|---|
| 最初に授かる | 火遁・息吹の術 | 前方範囲攻撃 |
| 最初に授かる | 水遁・水手裏剣の術 | 前方遠距離 |
| ボスまでに覚える | 雷遁・雷轟の術 | 遠距離範囲 |
| ボスまでに覚える | 土遁・岩戸の術 | 前方に巨大な岩を作る。盾になり、攻撃すると岩が飛ぶ。フィールドの仕掛けにも使う |

- 術符の補充は**拾う**（壺や草など）。敵のドロップは**基本お金**。

## 6. ボス（決定）

- **巨大スライム**。素材は後で追加する。
- 案: 1つの術だけでは倒しにくく、切り替えると楽になる相手（分裂した小スライムには範囲攻撃、本体には単発の高火力）。

## 7. 未定の論点

- 雷遁・土遁の巻物をどこで手に入れるか（宝箱・購入など）
- 各エリアの見た目（案: 森や竹林）
