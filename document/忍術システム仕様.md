# 忍者アドベンチャー 忍術システム仕様

最終更新: 2026-11-17

忍術（術）と術符の設計メモ。**決まったこと**と**未定のこと**を分けて書く。
状態の意味: `作成済` = エフェクト素材あり / `決定` = 仕様として採用 / `候補` = 採用寄りだが未確定 / `案` = まだ提案段階。

`素材カタログと規約.md` では術符を「未確定」としていたが、この文書の内容で**採用が決まった**。

---

## 1. コンセプト

- ラチェット＆クランクのように、**多様な術を切り替えて戦う**。クールタイム制ではない。
- 術は武器、**術符は弾薬**にあたる。術符が切れた術は撃てない。
- 刀・手裏剣などの基本攻撃は術符を使わず、常に使える（全部の術符が切れても詰まない）。

## 2. 術の習得（決定）

- 術は**巻物**を入手して覚える。
- 巻物の入手手段: お金で購入 / 素材と交換 / 宝箱。
- 手に入れた巻物を**村の修行場**に持ち込むと、術を覚えられる。
- 術には**前提条件**がある。指定された術を覚えていないと習得できない。前提条件は修行場で確認する。
- 具体的な前提関係（習得ツリー）は未定。

## 3. 術符（決定）

- 覚えた術は、**その術専用の術符を消費**して発動する。
- 術符は**術ごとに別々に所持**し、所持上限も術ごとに違う。
- 術符が0枚の術は発動できない（＝弾切れ）。
- 術符切れのとき、**他の術へ自動で切り替えない**。選択中のまま留まり、空撃ちの演出を出す。

### 表示と演出（UIで表現する）

術の発動アニメーションには術符を入れない。消費は**UI側**で見せる。

- 残数は術ホイールのスロット右下のバッジに表示する（カタログの規約どおり）。
- 発動時: 術符が燃えて消える短い演出（0.2〜0.3秒が目安）。
- 残りわずか: 警告表示（点滅など）。
- 術符切れ: 赤バッジ＋アイコン半透明（カタログの規約どおり）。発動操作をしたら、UIを小さく揺らして空撃ち音を鳴らす。
- 補充時: 枚数が増えたことが分かる演出。

### 補充（決定）

- 術符は**拾って補充**する。主に壺や草から出る。
- 敵のドロップは**基本お金**。術符は落とさない。
- 村の術符屋でも買える。
- 焚き火（セーブ地点）では補充しない。
- **術符は印ごと**（2026-11-18 決定）。落ちている術符は「火の術符」「水の術符」のように印で分かれる。拾うと、**持っている同じ印の術のうち、いちばん減っている術**（所持数÷上限が最小）が回復する。
- 1枚拾ったときの**回復枚数は術ごと**に違う。値は各術の `.tres` の `talisman_pickup`（仮: 火遁・息吹 3枚、水遁・水手裏剣 5枚）。
- ドロップの決め方は2種類（ドロップ表 `ResourceLoot` の各行で指定）:
  - **ランダム**: 覚えている術の印からランダム。満タンでない印を優先する。
  - **確定**: 印を指定（例: 宝箱の「水の術符2枚」）。その印の術を覚えていなければ出ない。
- 同じ印の術がすべて満タンなら、術符は吸い寄せられず地面に残る。

### 未定

- 術ごとの所持上限と消費枚数。
- 溜め撃ちの消費枚数（案: まず1枚で試し、強すぎたら増やす）。

## 4. 術のレベル

- 術にはレベルがある（カタログの規約どおり。最大レベルは紫バッジ）。
- **決定**: レベルは、ラチェット＆クランクのように**術ごとに、使うほど自動で上がる**。お金や素材は使わない。
- **決定**: 雷の術は、レベルアップで**連鎖**（当たった敵から近くの敵へ飛び移る）が解禁される。初期状態では連鎖しない。
- 未定: 経験値のたまり方（敵に当てた回数か、倒した数か）、最大レベル、他の印のレベルアップ効果。

## 5. 印（術のジャンル）

| 区分 | 印 | コンセプト | コンセプトの状態 |
|---|---|---|---|
| 基本 | 火 | 高火力・継続ダメージ | 案 |
| 基本 | 水 | **溜めて変化する**（チャージで術の形が変わる） | 決定 |
| 基本 | 雷 | **連鎖と貫通**（連鎖はレベルアップで解禁） | 決定 |
| 基本 | 風 | 未定（案: 敵を動かす＝引き寄せ・吹き飛ばし） | 未定 |
| 特殊 | 土 | **設置・トラップ** | 決定 |
| 特殊 | 氷 | 凍結 | 案 |

| 特殊 | 陰 | 搦め手 | 案 |

- 各印**3術**が目標。
- 風は当面1術のみ。氷・陽・陰は未着手。

## 8. 保留・未定

### 保留

- **合体術**: 2つの術を同時に選んで強力な術を撃ち、両方の術符を消費する案。要素が多くなるため保留。
- **起爆札の術**: 設置して、自分のタイミングで起爆するリモコン爆弾型の罠。保留。

### 未定

- 霧隠れ（`kirigakure`、素材あり）をどの印に入れるか。
- 風のコンセプトと、残り2術。
- 設置系の同時設置数の上限（案: 術ごとに2個まで。超えたら古いものから消す）。
- 埴輪兵の持続（時間制か弾数制か）。
- 岩戸の岩の消え方（案: 壁に当たったら砕けて消える。自分には当たらない）。
- 属性の相性（案: 濡れた敵に雷がよく効く、など）。
