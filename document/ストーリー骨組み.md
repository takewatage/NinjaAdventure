# 忍者アドベンチャー ストーリー骨組み

最終更新: 2026-11-17

状態の意味: `決定` = 作者が決めた筋 / `案` = Claude の提案で未採用 / `未定` = まだ決まっていない。

**体験版のストーリーは、この骨組みで進める（決定）。** 体験版の範囲は**最初のエリアのボスまで**（決定）。

## 1. あらすじ（決定）

1. 主人公は東京に住むシティボーイ。
2. ある日、ベッドで目を瞑って起きたら、忍者の世界に異世界転移していた。
3. 転移にわくわくするが、村の人は「今まで村の外に出たことがない」と言う。外に魔物が徘徊しているから。
4. 主人公は「アニメの異世界転移ならチート能力があるはず」と思い込み、外に出る。スライムが強すぎて、あっけなく敗北。
5. 村に戻ると、お爺さんから「この世界は忍びの世界だ」と教えられる。
6. この村は、忍びの里から離れた村。
7. お爺さんは元忍び。「修行させてやるから、忍びになって魔物を退治してほしい」と頼まれる。
8. 見習い忍者になった主人公が、魔物を倒しながら忍びの里を目指す。

## 2. 世界の背景（決定）

プレイヤーには最初は伏せておく真相。

### 過去に起きたこと（時系列）

1. お爺さんは昔、**伝説の忍者**と呼ばれていた。
2. **忍界を支配しようとする忍者（ラスボス）**が現れ、お爺さんはこれと対決した。
3. 戦いの中で、禁術**「百鬼口寄せの術」**を使わざるを得ない状況に追い込まれ、唱えてしまった。
4. しかし、それは**ラスボスの思う壺**だった。
5. お爺さんはギリギリのところで逃げ帰った。**禁術の代償**で、忍術が使えなくなった。
6. 世界は**魔物が召喚され続ける**状態になった。
7. お爺さんは責任をとって忍びを引退し、**自ら里を離れた**。里の人からは**死んだことになっている**。
8. 隠居しながら、いつか「百鬼口寄せの術」を**解除できる忍びを育てる（見つける）**ための準備をしていた。
9. お爺さんは**口寄せで主人公を呼んだ**。これが主人公の異世界転移の正体。忍術を失っているため、**長年かけて描いた陣と、ためこんだ術符**で発動した。8 の「準備」の中身がこれ。

### 忍びの里

- 禁術のことは**知っているが、誰も見たことがない伝承**になっている。
- お爺さんは死んだと思われている。

### お爺さんが主人公に隠していること

- **主人公を呼んだのが自分であること**。最初は教えない。

### 主人公の動機

- 元の世界に戻りたいというより、**たくさんの忍術を覚えたい**。好奇心が強い。

### ここから言えること

- 物語の最終目標は**「百鬼口寄せの術」の解除**と、**ラスボスとの決着**。
- お爺さんが自分で解除も退治もできないのは、禁術の代償で忍術を失ったから。
- 主人公の動機（術をたくさん覚えたい）は、多様な術を切り替えて戦うゲームの遊びと一致する。
- 術符さえあれば忍術を失った者でも術を発動できる、という世界の決まりになる。

## 3. 体験版の流れ

範囲は**最初のエリアのボスまで**（決定）。場面の割り方は案。

| 場面 | 内容 | 遊びとしての役割 |
|---|---|---|
| 東京の自室 | ベッドで目を瞑る。ごく短く | 導入。操作なし、または移動だけ |
| 村で目覚める | 村人と話す。「外には出られない」と聞く | 移動と会話の練習 |
| 村の外へ | チートを信じて飛び出す。スライムに負ける | **負けイベント**。攻撃手段がない状態で戦わせる |
| お爺さんの家 | 世界の説明と、魔物退治の依頼 | 目的の提示 |
| 修行 | 刀・手裏剣、最初の術を教わる | 戦闘チュートリアル |
| 再戦 | 同じスライムを倒す | 成長の実感 |
| 旅立ち | 忍びの里を目指して村を出る | 最初のエリアへ |
| 最初のエリア | 魔物を倒しながら進む。巻物と術符を手に入れる | 術の切り替え、術符の補充、焚き火でのセーブ |
| エリアのボス | ボスを倒す | 体験版の山場 |
| 体験版の終わり | 先の道が開け、続きを予感させて終わる | 製品版への引き |

修行でお爺さんは術を**実演できない**（忍術を失っているため）。口と巻物で教えることになる。主人公が「なんで見せてくれないの」と不思議がる場面は、後の真相の伏線にできる（案）。

### 最初のエリアとボス（案）

- **舞台**: 村を出てすぐの森や竹林。村人が恐れてきた「外」そのもの。
- **ボス（決定）**: 巨大スライム。素材は後で追加する。冒頭でスライムに負けた主人公が、最後にその親玉を倒す。体験版だけで「負け → 修行 → 勝ち」の話が閉じる。
- **使える術（決定）**: 火遁・息吹、水遁・水手裏剣（最初に授かる）、雷遁・雷轟、土遁・岩戸（ボスまでに覚える）の4術。
- **ボスの作り**: 1つの術だけでは倒しにくく、切り替えると楽になる相手にする（例: 分裂した小スライムには範囲攻撃、本体には単発の高火力）。
- **終わり方**: ボスを倒すと、主人公が来たことを知る何者かの影を一瞬見せる（ラスボス側の引き）。真相は明かさない。

## 4. 忍術システムとのつながり（案）

`忍術システム仕様.md` の決定事項を、物語の中でどう説明するか。

- **基本攻撃（刀・手裏剣）**: 修行の最初に教わる。スライムに負けたのは、これすら持っていなかったから。
- **巻物で術を覚える**: 最初の巻物はお爺さんから授かる。以降は購入・素材交換・宝箱。
- **術符**: お爺さんが最初の束をくれる。「術は符がなければ撃てん」と教わる場面で、弾切れの仕組みを説明できる。
- **最初の術（決定）**: 火遁・息吹の術と水遁・水手裏剣の術の2つ。
- **術の前提条件**: 「基礎の術を修めないと上の術は扱えない」という忍びの掟として説明できる。
- **焚き火（セーブ地点）**: 旅の野営地。村の外の道中に置く。できるのは**セーブだけ**（決定）。
- **術を覚えるほど解除に近づく**（案）: 解除には多くの術の習得が必要、とすると、主人公の好奇心・ゲームの収集要素・最終目標が1本につながる。

## 5. 背景についての案

- **真相を明かす順番**（案）。序盤は「魔物を退治してほしい」とだけ頼む。里で「伝説の忍者は死んだ」「禁術は伝承」と聞き、プレイヤーが先に気づく。その後、お爺さん本人の口から、禁術を唱えたこと、主人公を呼んだことの順に明かす。
- **ラスボスの狙い**（案）。「思う壺」の中身。次のどれか。
  - 魔物は術者ではなくラスボスに従う。禁術はラスボスの軍勢を作るための罠だった。
  - 邪魔な伝説の忍者から忍術を奪うことが目的だった。
  - その両方。

### 体験版のあとで決める

- **ラスボスの狙いと現在**。なぜ禁術を使わせたかったのか。今どこで何をしているのか（魔物を従えて支配を進めている、力を蓄えている、里の中に潜んでいる、など）。名前も未定。
- **里は魔物の原因を知っているのか**。禁術が伝承なら、里の人は魔物がなぜ現れるのかを知らないことになる。
- **里を目指す理由**。主人公にとって（案: 多くの巻物がある）、お爺さんにとって（案: 解除の手がかりや禁術の巻物がある）。
- **術が唱えられたのはどれくらい前か**。村人が「外に出たことがない」、里で伝承になっている、という点から数十年前になる。
- **なぜ主人公が呼ばれたのか**。たまたまか、解除の素質があるからか。「チートはない」という序盤の笑いと、どう両立させるか。
- **話の調子**。あらすじはコメディ寄り。背景は重め（お爺さんの罪と償い）。両方をどう混ぜるか。
- 村から里までの道のり（2つ目以降のエリアの数、各エリアの印やボス）。
